ممتاز. RBAC Enforcement Patch مقبول مبدئياً، والخلل الحرج السابق أُغلق.

نوافق على إضافة Audit Log Viewer، لكن فقط كنطاق Phase 1.1 Security Visibility، وليس كميزة جديدة واسعة.

نفّذ Audit Log Viewer فقط بالشروط التالية:

Backend:
1. أضف أو ثبّت endpoint:
   GET /api/audit-logs

2. يجب أن يكون محمياً بـ:
   requireSession
   requirePermission("audit_logs:read")

3. يجب أن يكون workspace-scoped فقط:
   - workspace_id من session
   - لا تقبل workspace_id من body أو query
   - أي فلترة تكون داخل activeWorkspaceId فقط

4. الفلاتر المسموحة:
   - action
   - entity_type
   - severity
   - actor_id
   - date_from
   - date_to
   - search اختياري في actor_label/entity_label
   - pagination: page, pageSize

5. لا تضف create/update/delete لأي audit log.
   audit_logs read-only بالكامل.

6. لا تعرض old_data/new_data الخام بشكل خطر للمستخدم العادي.
   اعرضها داخل details panel للـ owner/manager فقط إذا كان لديه audit_logs:read.
   لا تعرض passwords أو secrets إن وجدت.

Frontend:
1. أضف صفحة "السجلات" أو فعّل صفحة موجودة:
   /app/audit-logs أو المسار الحالي في القائمة.

2. الصفحة يجب أن تحتوي:
   - جدول أو قائمة سجلات
   - فلترة حسب الإجراء
   - فلترة حسب نوع الكيان
   - فلترة حسب الخطورة
   - فلترة حسب التاريخ
   - بحث
   - pagination
   - empty state عربي
   - loading state
   - error state مع زر "إعادة المحاولة"
   - permission denied state:
     "ليس لديك صلاحية لعرض سجل النشاطات"

3. لا تضف تعديل أو حذف للسجلات.
4. لا تضف export الآن.
5. لا تضف analytics أو charts الآن.
6. لا تضف أي ميزة أخرى.

RBAC verification بعد التنفيذ:
- owner GET /api/audit-logs → 200
- manager GET /api/audit-logs → 200 إذا كان manager يملك audit_logs:read في seed
- accountant GET /api/audit-logs → حسب seed الحالي؛ إن كان يملكها → 200، إن لم يملكها → 403
- viewer GET /api/audit-logs → 403
- agent GET /api/audit-logs → 403

Final verification:
- اعرض قائمة كل routes والصلاحية المطبقة عليها، أو على الأقل أكّد أنه لا توجد route تشغيلية بدون requirePermission.
- اعرض نتيجة typecheck backend/frontend.
- اعرض الملفات التي تغيرت.
- لا تبدأ Phase 2.
- لا تضف Debts.
- لا تضف AI.
- لا تضف integrations.
- لا تضف أي جداول جديدة إلا إذا كان audit endpoint يحتاج index بسيط موجود في schema.
- لا تحذف ملفات.

بعد التنفيذ توقف وانتظر الموافقة.
