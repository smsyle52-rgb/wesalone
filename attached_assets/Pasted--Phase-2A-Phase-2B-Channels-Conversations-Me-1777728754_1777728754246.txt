Phase 2B Scope:

1. Channels Foundation

ثبّت أو أضف:
- channels كأنواع عامة إن كانت موجودة
- channel_accounts داخل workspace

يجب دعم القنوات التالية كحالات:
- whatsapp_manual: active
- website_widget: active أو placeholder
- whatsapp_api: pending_meta_review / disabled
- telegram: coming_soon
- instagram: coming_soon
- messenger: coming_soon
- voice: coming_soon

لا تفعّل أي تكامل خارجي.
كل القنوات الخارجية تكون disabled أو coming soon مع سبب عربي واضح.

channel_accounts يجب أن تحتوي:
- id
- workspace_id
- channel_type
- name
- status
- display_name
- provider_config JSONB
- credentials_secret_ref nullable
- created_by
- created_at
- updated_at

ممنوع تخزين tokens أو secrets في DB.

2. Conversations

ثبّت أو أضف:
- GET /api/conversations
- POST /api/conversations
- GET /api/conversations/:id
- PATCH /api/conversations/:id
- PATCH /api/conversations/:id/assign
- PATCH /api/conversations/:id/status

conversation fields المطلوبة:
- workspace_id
- contact_id
- contact_channel_id nullable
- channel_account_id nullable
- external_thread_id nullable
- assigned_to nullable
- team_id nullable
- status: new | open | pending | snoozed | bot | resolved | closed
- priority: low | normal | high | urgent
- subject
- last_message_at
- last_message_preview
- unread_count
- ai_summary nullable
- snoozed_until nullable
- resolved_at nullable
- closed_at nullable

3. Messages

ثبّت أو أضف:
- GET /api/conversations/:id/messages
- POST /api/conversations/:id/messages
- PATCH /api/messages/:id/read إن كان مناسباً

message fields المطلوبة:
- workspace_id
- conversation_id
- provider_message_id nullable
- direction: inbound | outbound | internal
- sender_type: contact | user | ai | system
- sender_id nullable
- source: manual | paste | widget | api | automation
- content_type: text | image | audio | document | note
- content أو body موحّد في backend/frontend، اختر واحداً وطبّقه في كل مكان
- is_ai_draft default false
- is_private_note default false
- delivery_status: pending | sent | delivered | read | failed
- provider_payload JSONB
- sent_at

مهم:
لا تخلط body و content بين frontend/backend.
اختر اسم واحد. الأفضل: content.

4. Manual WhatsApp + wa.me

أضف داخل واجهة Inbox:
- زر "فتح واتساب"
- يولّد wa.me من رقم whatsapp أو phone في contact_channels
- إذا لا يوجد رقم، الزر disabled مع سبب:
  "لا يوجد رقم واتساب لهذا العميل"

لا تقرأ الرسائل من WhatsApp.
لا تعمل scraping.
لا WhatsApp API.

5. Copy/Paste Import

أضف أو ثبّت:
- زر "لصق محادثة"
- modal لإدخال نص المحادثة
- يحفظها كرسائل source=paste
- إن لم يمكن تقسيمها بدقة، احفظها كرسالة واحدة أو transcript message
- أضف timeline event:
  conversation_imported

لا تبالغ في parser الآن.
الأولوية للاستقرار.

6. Inbox UI

طوّر صندوق الوارد إلى:
- قائمة محادثات
- بحث
- فلترة حسب status
- فلترة حسب assignee
- فلترة حسب channel
- عرض تفاصيل المحادثة
- عرض الرسائل
- إرسال رسالة manual داخل النظام
- إضافة internal note
- تغيير الحالة
- إسناد موظف

كل أزرار التحويل إلى:
- تذكرة
- مهمة
- فرصة
- طلب
- دفعة

تكون disabled الآن مع سبب:
"سيتم تفعيل هذا الإجراء في مرحلة العمليات"

7. RBAC

طبّق permissions:
- conversations:read
- conversations:create
- conversations:update
- conversations:reply
- conversations:assign
- conversations:resolve

إن كانت permission ناقصة، أضفها للـ seed بعناية.

الحد الأدنى:
- owner/manager: كل شيء
- agent: read/create/reply/update/assign حسب seed
- viewer: read فقط
- accountant: غالباً read فقط أو لا شيء حسب seed

8. Workspace Isolation

كل routes:
- requireSession
- requirePermission
- workspace_id من session فقط
- لا تقبل workspace_id من body/query
- أي resource lookup يجب أن يطابق activeWorkspaceId

10. State Machine

conversation.status transitions:
- new → open
- open → pending
- pending → open
- open → snoozed
- snoozed → open
- open → bot
- bot → open
- open → resolved
- resolved → open
- resolved → closed

closed لا يُعاد فتحه إلا owner/manager أو permission conversations:reopen إن قررت إضافتها.

لا تسمح بحالات خارج هذه القائمة.

- empty state
- error state

- RTL
- mobile layout بدون كسر واضح
- لا نصوص إنجليزية للمستخدم

12. اختبارات إلزامية

Typecheck:
- pnpm --filter @workspace/api-server run typecheck
- pnpm --filter @workspace/web run typecheck
- pnpm run typecheck:libs إن لزم

RBAC:
- viewer GET /api/conversations → 200
- viewer POST /api/conversations → 403
- viewer POST /api/conversations/:id/messages → 403
- agent POST /api/conversations → حسب seed، اذكر النتيجة
- agent POST /api/conversations/:id/messages → 201 إذا يملك conversations:reply
- owner PATCH /api/conversations/:id/assign → 200
- viewer PATCH /api/conversations/:id/assign → 403

Workspace isolation:
- POST /api/conversations مع workspace_id مختلف في body → يتجاهله
- POST /api/conversations/:id/messages على conversation من workspace آخر → 404 أو 403

Messages:
- إنشاء رسالة outbound يحدّث last_message_preview و last_message_at
- إنشاء رسالة inbound يزيد unread_count إذا مناسب
- internal note لا تظهر كرسالة عميل

wa.me:
- contact لديه whatsapp channel → الزر يولد رابط صحيح
- contact بلا رقم → الزر disabled مع سبب عربي

Copy/Paste:
- لصق محادثة ينشئ messages أو transcript
- يسجل audit log
- يضيف timeline event

Audit/Timeline:
- conversation create يسجل audit + timeline
- message create يسجل audit + timeline
- status change يسجل audit + timeline
- assignment يسجل audit + timeline
