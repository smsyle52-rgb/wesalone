3. State Machines

Tickets:
- new → open
- open → in_progress
- in_progress → waiting_on_customer
- waiting_on_customer → in_progress
- in_progress → resolved
- resolved → closed
- resolved → open
- closed terminal

Tasks:
- pending → in_progress
- in_progress → done
- pending → done
- pending → cancelled
- in_progress → cancelled
- done/cancelled terminal

Followups:
- pending → done
- pending → skipped
- pending → overdue
- overdue → done
- overdue → skipped
- done/skipped terminal
- skipped requires skipped_reason

Opportunities:
- new → qualified
- qualified → proposal
- proposal → negotiation
- negotiation → won
- negotiation → lost
- any non-terminal → lost
- won/lost terminal
- lost requires lost_reason

لا تسمح بحالات خارج هذه القوائم.

11. اختبارات إلزامية

Typecheck:
- pnpm --filter @workspace/api-server run typecheck
- pnpm --filter @workspace/web run typecheck
- pnpm run typecheck:libs إن لزم

RBAC:
- viewer GET /api/tickets → 200
- viewer POST /api/tickets → 403
- agent POST /api/tickets → 201
- viewer POST /api/tasks → 403
- agent POST /api/tasks → 201
- viewer POST /api/followups → 403
- agent POST /api/followups → 201
- viewer POST /api/opportunities → 403
- agent POST /api/opportunities → 201

Workspace isolation:
- POST ticket/task/followup/opportunity مع workspace_id مختلف في body → يتجاهله
- إنشاء operation على contact من workspace آخر → 404 أو 403
- إنشاء operation على conversation من workspace آخر → 404 أو 403

State machines:
- ticket closed لا يُعاد فتحه
- task done لا يعود pending
- followup skipped بدون skipped_reason → 400
- opportunity lost بدون lost_reason → 400
- opportunity won/lost terminal

Quick actions:
- من conversation يتم إنشاء ticket/task/followup/opportunity ويرتبط بـ conversation_id و contact_id
- من contact profile يتم إنشاء ticket/task/followup/opportunity ويرتبط بـ contact_id

Audit/Timeline:
- كل create/update/status change يسجل audit
- كل create/status change يظهر في contact timeline

UI:
- صفحات العمليات RTL
- أزرار Orders/Payments/Debts لا تزال disabled مع سبب عربي
- لا نصوص إنجليزية للمستخدم
- error states موجودة
