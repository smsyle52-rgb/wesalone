ابدأ Phase 7C.1 فقط:
Apply Reviewed Migration 0001 to Dev Database.

Scope:

1. Backup / Snapshot قبل التطبيق

قبل تشغيل migrate:
- خذ backup snapshot أو dump من قاعدة dev الحالية إن أمكن.
- إذا لا يمكن dump في Replit، وثّق السبب بوضوح.
- على الأقل نفّذ queries توثيقية قبل التطبيق:

report_definitions:
- SELECT is_archived, COUNT(*) FROM report_definitions GROUP BY is_archived;

tickets:
- SELECT COUNT(*) total, COUNT(team_id) non_null FROM tickets;

conversations:
- SELECT COUNT(*) total, COUNT(team_id) non_null FROM conversations;

2. Apply Migration

طبّق فقط migration 0001 على dev DB:

- pnpm --filter @workspace/db run migrate

لا تستخدم db:push.
لا تستخدم reset.
لا تستخدم force.

3. Post-Migration Verification

بعد التطبيق، تحقق من:

report_definitions:
- is_archived أصبح boolean
- القيم القديمة:
  - 'true' أصبحت true
  - 'false' أصبحت false

tickets:
- team_id أصبح uuid nullable
- FK إلى teams(id) موجود

conversations:
- team_id أصبح uuid nullable
- FK إلى teams(id) موجود

drizzle migration journal:
- 0001_common_serpent_society مسجل كمطبق

4. App Verification

شغّل:
- pnpm run typecheck:libs
- pnpm --filter @workspace/api-server run typecheck
- pnpm --filter @workspace/web run typecheck

ثم تحقق:
- GET /api/healthz → 200

Smoke tests:
- GET /api/reports/definitions يعمل

5. Destructive Safety

أكد بعد التطبيق:
- لم يتم تشغيل DROP
