نفّذ فقط:

Phase 5B.1 — AI Safety + Knowledge Integration Patch

Scope:

1. Safety Events for Blocked Tool Actions

في route الخاص بتعديل أدوات الوكيل أو تفعيل tool:
إذا حاول المستخدم تفعيل tool_key محظور مثل:
- payment.confirm
- payment.reject
- payment.update_status
- debt.write_off
- role.change
- user.invite
- integration.activate
- message.auto_send
- data.delete

يجب أن يحدث الآتي:
- ترجع 400 كما يحدث الآن
- تسجل ai_safety_event داخل نفس workspace
- event_type = blocked_tool_enable أو blocked_action
- severity = critical للأفعال المالية والصلاحيات والحذف
- blocked_action = tool_key
- reason = الرسالة العربية
- payload يحتوي agent_id و tool_key و actor_id إن أمكن

لا تنفذ أي mutation على agent_tools.
لا تفعّل الأداة.
لا تغير أي كيان مالي أو صلاحية.

2. Optional AI Run Link

إذا لم يكن هناك ai_run_id في حالة tools route، اجعله nullable كما هو في schema.
المهم أن ai_safety_events تسجل الحدث حتى بدون ai_run.

3. Knowledge Integration End-to-End Test Fix

أصلح اختبار أو flow إنشاء document المستخدم في Knowledge Integration.

المطلوب:
- أن يستطيع owner إنشاء knowledge base
- ثم إنشاء document نصي صحيح داخلها
- document ينتج chunks
- draft-reply يستخدم searchKnowledge
- response metadata أو run messages تحتوي knowledgeSources عند وجود نتائج

إذا كان الخطأ بسبب missing source_id:
- source_id يجب أن يكون nullable فعلياً أو أن flow الاختبار ينشئ source أولاً
- لا تكسر schema
- اختر الحل الأكثر اتساقاً مع Phase 5A

4. Draft Reply Knowledge Metadata

عند draft-reply:
- إذا وُجدت knowledge sources، احفظها في ai_messages.metadata أو ai_run metadata إن كان موجوداً
- لا embeddings
- لا Vector Search
- لا Gemini RAG
- فقط ilike search الحالي

5. Approval Reject Reason

راجع approval reject:
- إذا reason اختياري حالياً، اذكر هل هذا مقصود.
- الأفضل: اجعل reason مطلوباً عند reject برسالة عربية:
  "يجب إدخال سبب رفض الاعتماد"
إذا سيؤثر على UI، طبّقه بشكل بسيط.

6. Test Agent Button

زر "اختبار" في AgentsPage يستخدم محادثة وهمية.
لا تجعله يبدو كاختبار حقيقي على بيانات فعلية.
إما:
- غيّر النص إلى "اختبار تجريبي"
- أو اجعله يتطلب اختيار محادثة فعلية
الأفضل الآن: "اختبار تجريبي" مع توضيح:
"يعمل بوضع mock ولا يرسل أي رسالة"
