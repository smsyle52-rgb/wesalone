قبل بدء الكود، طبّق هذه التصحيحات التنفيذية النهائية على الخطة فقط، ثم ابدأ Phase 1 فقط.

تصحيحات إلزامية:

1. لا تنفذ كل schema دفعة واحدة.
   Phase 1 يجب أن تشمل Core / Security فقط:
   workspaces, users, workspace_memberships, roles, permissions,
   role_permissions, membership_roles, teams, team_members,
   sessions, audit_logs, login_events, feature_flags, plans, subscriptions.

2. أنشئ جدول files قبل أي جدول يستخدم file_id.
   لا تنشئ message_attachments أو report_exports أو knowledge_documents.file_id قبل files.

3. لا تخزن أي secrets أو provider tokens داخل PostgreSQL.
   استخدم secret reference fields فقط:
   credentials_secret_ref, webhook_secret_ref, provider_secret_ref.
   أثناء التطوير استخدم env variables.
   لاحقاً سنستخدم Google Secret Manager.

4. اجعل نموذج files جاهزاً لـ Google Cloud Storage:
   storage_provider = 'gcs'
   bucket
   object_key
   original_name
   mime_type
   size_bytes
   scan_status
   is_public
   ولا تعتمد على local file paths.

5. وحّد status enums بين state machines والـ database والـ UI.
   أضف conversation.status = closed رسمياً، أو احذف closed من automation.
   القرار: أضف closed رسمياً.
   الحالات:
   new, open, pending, snoozed, bot, resolved, closed.

6. لا تستخدم to_tsvector('arabic') إلا إذا أنشأت Arabic text search config.
   في البداية استخدم simple أو pg_trgm للبحث العربي.

7. اجعل payment_methods جدولاً حقيقياً.
   payments يجب أن تحتوي:
   payment_method_id
   method_snapshot
   وليس method TEXT فقط.

8. أضف snapshot لسعر الصرف في orders وpayments:
   exchange_rate_id nullable
   exchange_rate_snapshot
   base_amount_yer

9. أضف outbox_events لدعم الأحداث لاحقاً:
   id, workspace_id, event_type, entity_type, entity_id, payload,
   status, attempts, next_attempt_at, created_at, published_at.

10. لا تنفذ AI أو payments أو inbox أو integrations في Phase 1.
    فقط جهّز feature_flags والحواجز الأمنية:
    whatsapp_api_enabled = false
    ai_auto_send = false
    ai_confirm_payments = false
    voice_enabled = false
    payment_providers_enabled = false

بعد تعديل الخطة داخلياً، ابدأ Phase 1 فقط.
لا تبدأ Phase 2.
لا تنشئ كل الجداول.
لا تنفذ أي تكامل خارجي.
